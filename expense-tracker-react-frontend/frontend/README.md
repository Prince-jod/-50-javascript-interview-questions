# Expense Tracker - React Frontend

Backend (Express) is unchanged. This replaces everything in `public/`.

## Run (development)
1. Start the backend as usual:  `cd expense-tracker && node server.js`  (port 3000)
2. In this folder:
   npm install
   npm run dev
3. Open http://localhost:5173  (calls to /api are proxied to port 3000)

## Pages
/login, /signup, /dashboard  (same buttons and API calls as before:
login, forgot password, register, add/edit/delete expense, premium payment (Cashfree),
leaderboard, download PDF, logout)
